End-to-End Pipeline

The 4-Phase Migration Methodology

A battle-tested workflow designed to move enterprise Salesforce orgs to the Principle of Least Privilege.

Phase 01

Scan & Audit

Audit complexity scores, inventory SObjects and FLS, detect high-risk system grants, and export an executive HTML dashboard.

permforge analyze && report
Phase 02

Cluster & Decompose

Extract shared baseline permissions across all profiles and slice role-specific grants into modular domain Permission Sets and PSGs.

permforge cluster && decompose
Phase 03

Parity Verification

Audit the generated sets against original profiles bit-for-bit. Math proof guarantees 100% equivalence before touching production.

permforge verify -p <prof> -g <psg>
Phase 04

Sanitize & Deploy

Strip legacy permissions from profiles, generate User Access Policies for auto-assignment, and produce rollback scripts.

permforge strip && uap && plan
Command Line Interface

Complete CLI Reference

13 purpose-built commands covering discovery, decomposition, verification, and automated assignment.

permforge analyze Audit

Inventories profile SObject & FLS permissions, computes 0-100 complexity debt score, and flags high-risk permissions.

permforge analyze -d force-app/main/default/profiles
permforge cluster Migration

Cross-profile similarity analyzer. Extracts shared Standard_Employee_Baseline and role-specific delta sets.

permforge cluster -d force-app/.../profiles -t 0.70
permforge decompose Migration

Modularizes a profile into single-responsibility domain Permission Sets and a persona Permission Set Group.

permforge decompose -p CustomSales.profile-meta.xml
permforge verify Validation

Mathematically verifies 100% access parity between a source Profile and a target Permission Set Group.

permforge verify -p CustomSales.profile -g Sales.psg
permforge strip Sanitize

Strips migratable permissions from profiles while keeping layout assignments, login hours, and IP ranges intact.

permforge strip -p CustomSales.profile -o cleaned/
permforge uap Automation

Generates declarative User Access Policies (.userAccessPolicy-meta.xml) to automate PSG assignment on user record changes.

permforge uap -n Assign_Sales -g Sales_Rep_PSG
permforge mute Subtractive

Generates Muting Permission Sets (.mutingpermissionset-meta.xml) for subtractive permissions within PSGs.

permforge mute -n Mute_Delete -s Account:delete
permforge lint CI/CD

Pre-commit and pull request linter. Emits GitHub Actions annotations to prevent profile regression.

permforge lint -d force-app/.../profiles --strict
permforge graph Topology

Visualizes PSG inheritance hierarchy and object grant dependencies as Mermaid diagrams or ASCII trees.

permforge graph -g Sales_Rep_PSG.permissionsetgroup
permforge report Reporting

Generates a self-contained interactive HTML audit report with security debt charts, risk tables, and export options.

permforge report -d force-app/ -o audit.html
permforge plan Execution

Generates complete migration runbook: user assignment CSVs, rollback scripts, and SF CLI deploy sequences.

permforge plan -p CustomSales.profile -o migration/
permforge wizard Interactive

Interactive terminal wizard that guides admins step-by-step through discovery, clustering, decomposition, and parity checks.

permforge wizard
permforge mcp AI Agent

Starts the native Model Context Protocol (MCP) server over stdio for autonomous AI coding agents.

permforge mcp
